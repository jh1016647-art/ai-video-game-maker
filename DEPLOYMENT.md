# AI Video + Game Maker - Production Deployment Guide\n\n## Overview\n\nThis guide covers deploying the AI Video + Game Maker studio to production with a full tech stack:\n- Node.js backend\n- PostgreSQL database\n- OpenAI API (text generation)\n- Replicate API (video generation)\n- JWT authentication\n- Secure environment configuration\n\n## Prerequisites\n\nBefore deploying, you need:\n\n1. **OpenAI API Key**\n   - Go to https://platform.openai.com/api/keys\n   - Create a new API key\n   - Save it securely\n\n2. **Replicate API Token**\n   - Go to https://replicate.com/account/api-tokens\n   - Create a new API token\n   - Save it securely\n\n3. **GitHub Account**\n   - Repo: https://github.com/jh1016647-art/ai-video-game-maker\n   - Ensure repo is public or private (depending on deployment needs)\n\n4. **Deployment Platform Account**\n   - Choose one: Render, Railway, Heroku, or Docker-based\n\n---\n\n## Option 1: Render Deployment (Recommended)\n\n**Why Render:**\n- Easiest setup for Node apps\n- Built-in PostgreSQL support\n- Free tier available\n- Automatic deployments from GitHub\n\n### Step 1: Create Render Account\n\n1. Go to https://render.com\n2. Sign up with GitHub account\n3. Authorize access to your repo\n\n### Step 2: Create a PostgreSQL Database\n\n1. In Render dashboard, click **New +**\n2. Select **PostgreSQL**\n3. Name it: `ai-studio-db`\n4. Region: Choose closest to you\n5. PostgreSQL Version: 15\n6. Instance Type: Standard (free tier available)\n7. Click **Create Database**\n8. Wait for initialization (2-3 minutes)\n9. Copy the **Internal Database URL** (you'll need this)\n\n### Step 3: Create Web Service\n\n1. Click **New +**\n2. Select **Web Service**\n3. Connect your GitHub repo\n4. Name: `ai-video-game-maker`\n5. Region: Same as database\n6. Branch: `main`\n7. Runtime: `Node`\n8. Build Command: `npm install`\n9. Start Command: `node migrate.js && npm start`\n10. Plan: Choose based on needs (free tier available)\n\n### Step 4: Set Environment Variables\n\n1. In Web Service settings, go to **Environment**\n2. Add each variable:\n\n```\nOPENAI_API_KEY=sk-your-actual-openai-key\nOPENAI_MODEL=gpt-4o-mini\nREPLICATE_API_TOKEN=your-actual-replicate-token\nDATABASE_URL=postgresql://user:password@host:5432/ai_studio\nJWT_SECRET=generate-a-long-random-string-here-at-least-32-chars\nNODE_ENV=production\nPORT=3000\n```\n\n**How to generate JWT_SECRET:**\n```bash\nnode -e \"console.log(require('crypto').randomBytes(32).toString('hex'))\"\n```\n\n3. Click **Save**\n\n### Step 5: Deploy\n\n1. Render automatically deploys when you push to main\n2. Or click **Manual Deploy** in the dashboard\n3. Wait for build to complete (3-5 minutes)\n4. Once \"Deploy live\" appears, your app is live\n5. View at: `https://ai-video-game-maker.onrender.com`\n\n### Step 6: Verify Deployment\n\n```bash\ncurl https://ai-video-game-maker.onrender.com/api/health\n```\n\nYou should see:\n```json\n{\n  \"status\": \"ok\",\n  \"name\": \"AI Video and Game Maker\",\n  \"version\": \"3.0.0\",\n  \"aiEnabled\": true,\n  \"videoEnabled\": true,\n  \"environment\": \"production\"\n}\n```\n\n---\n\n## Option 2: Railway Deployment\n\n**Why Railway:**\n- Very fast setup\n- Integrated PostgreSQL\n- Good free tier\n\n### Step 1: Create Railway Account\n\n1. Go to https://railway.app\n2. Sign up with GitHub\n3. Authorize repo access\n\n### Step 2: Create New Project\n\n1. Click **New Project**\n2. Select **GitHub Repo**\n3. Choose `ai-video-game-maker`\n4. Click **Deploy**\n\n### Step 3: Add PostgreSQL\n\n1. In project dashboard, click **Add Service**\n2. Select **PostgreSQL**\n3. Railway creates DB automatically\n\n### Step 4: Set Environment Variables\n\n1. Go to **ai-video-game-maker** service\n2. Click **Variables**\n3. Add:\n\n```\nOPENAI_API_KEY=sk-your-actual-openai-key\nOPENAI_MODEL=gpt-4o-mini\nREPLICATE_API_TOKEN=your-actual-replicate-token\nJWT_SECRET=generate-a-long-random-string-here\nNODE_ENV=production\n```\n\n4. Railway automatically links DATABASE_URL from PostgreSQL service\n\n### Step 5: Deploy\n\n1. Click **Deployments**\n2. Watch build progress\n3. Once complete, click **View Domain**\n\n---\n\n## Option 3: Heroku Deployment\n\n**Why Heroku:**\n- Classic app platform\n- GitHub integration\n- Easy CLI deployment\n\n### Step 1: Install Heroku CLI\n\n```bash\n# macOS\nbrew tap heroku/brew && brew install heroku\n\n# Windows\nchoco install heroku-cli\n\n# Linux\ncurl https://cli-assets.heroku.com/install.sh | sh\n```\n\n### Step 2: Create App\n\n```bash\nheroku login\nheroku create ai-video-game-maker\n```\n\n### Step 3: Add PostgreSQL\n\n```bash\nheroku addons:create heroku-postgresql:hobby-dev\n```\n\n### Step 4: Set Environment Variables\n\n```bash\nheroku config:set OPENAI_API_KEY=sk-your-actual-openai-key\nheroku config:set OPENAI_MODEL=gpt-4o-mini\nheroku config:set REPLICATE_API_TOKEN=your-actual-replicate-token\nheroku config:set JWT_SECRET=generate-a-long-random-string-here\nheroku config:set NODE_ENV=production\n```\n\nVerify:\n```bash\nheroku config\n```\n\n### Step 5: Deploy\n\n```bash\ngit push heroku main\n```\n\n### Step 6: Run Migrations\n\n```bash\nheroku run node migrate.js\n```\n\n### Step 7: Open App\n\n```bash\nheroku open\n```\n\n---\n\n## Option 4: Docker Deployment\n\n**Why Docker:**\n- Portable\n- Works anywhere (local, AWS, Google Cloud, DigitalOcean)\n- Great for learning\n\n### Step 1: Create Dockerfile\n\nCreate `Dockerfile` in repo root:\n\n```dockerfile\nFROM node:20-alpine\n\nWORKDIR /app\n\nCOPY package*.json ./\nRUN npm install\n\nCOPY . .\n\nEXPOSE 3000\n\nCMD [\"npm\", \"start\"]\n```\n\n### Step 2: Create docker-compose.yml\n\nFor local testing with full stack:\n\n```yaml\nversion: '3.8'\n\nservices:\n  db:\n    image: postgres:15-alpine\n    environment:\n      POSTGRES_USER: aiuser\n      POSTGRES_PASSWORD: aipassword\n      POSTGRES_DB: ai_studio\n    ports:\n      - \"5432:5432\"\n    volumes:\n      - postgres_data:/var/lib/postgresql/data\n\n  app:\n    build: .\n    ports:\n      - \"3000:3000\"\n    environment:\n      DATABASE_URL: postgresql://aiuser:aipassword@db:5432/ai_studio\n      OPENAI_API_KEY: ${OPENAI_API_KEY}\n      REPLICATE_API_TOKEN: ${REPLICATE_API_TOKEN}\n      JWT_SECRET: ${JWT_SECRET}\n      NODE_ENV: production\n    depends_on:\n      - db\n    command: sh -c \"node migrate.js && npm start\"\n\nvolumes:\n  postgres_data:\n```\n\n### Step 3: Build and Run Locally\n\n```bash\n# Create .env file with your API keys\necho \"OPENAI_API_KEY=sk-your-key\" > .env\necho \"REPLICATE_API_TOKEN=your-token\" >> .env\necho \"JWT_SECRET=$(node -e 'console.log(require(\\\"crypto\\\").randomBytes(32).toString(\\\"hex\\\"))')\" >> .env\n\n# Build and start\ndocker-compose up --build\n```\n\nApp runs at http://localhost:3000\n\n### Step 4: Deploy to Production\n\n**AWS EC2:**\n\n```bash\n# SSH into your EC2 instance\nssh -i your-key.pem ec2-user@your-instance-ip\n\n# Install Docker\nsudo yum update -y\nsudo yum install docker -y\nsudo systemctl start docker\n\n# Clone repo\ngit clone https://github.com/jh1016647-art/ai-video-game-maker.git\ncd ai-video-game-maker\n\n# Create .env with production values\nsudo nano .env\n\n# Run\nsudo docker-compose up -d\n```\n\n**DigitalOcean App Platform:**\n\n1. Go to https://cloud.digitalocean.com/apps\n2. Click **Create App**\n3. Connect GitHub repo\n4. Select `ai-video-game-maker`\n5. DigitalOcean auto-detects Dockerfile\n6. Add PostgreSQL database in resources\n7. Set environment variables\n8. Deploy\n\n---\n\n## Post-Deployment Checklist\n\n### Verify App is Running\n\n```bash\ncurl https://your-app-url.com/api/health\n```\n\nExpected response:\n```json\n{\n  \"status\": \"ok\",\n  \"aiEnabled\": true,\n  \"videoEnabled\": true,\n  \"environment\": \"production\"\n}\n```\n\n### Test User Registration\n\n```bash\ncurl -X POST https://your-app-url.com/api/register \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"username\": \"testuser\",\n    \"email\": \"test@example.com\",\n    \"password\": \"testpassword123\"\n  }'\n```\n\n### Test Login\n\n```bash\ncurl -X POST https://your-app-url.com/api/login \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\n    \"username\": \"testuser\",\n    \"password\": \"testpassword123\"\n  }'\n```\n\nYou should get a JWT token in response.\n\n### Test Project Generation\n\n```bash\ncurl -X GET \"https://your-app-url.com/api/generate?prompt=cyberpunk%20city\" \\\n  -H \"Authorization: Bearer YOUR_JWT_TOKEN\"\n```\n\n---\n\n## Monitoring & Logging\n\n### Render\n\n1. Check logs for errors\n2. Verify DATABASE_URL is correct\n3. Ensure migrations ran: `node migrate.js`\n4. Check Node version (requires 18+)\n\n### Database connection fails\n\n1. Verify DATABASE_URL format\n2. Check database is running\n3. Verify firewall rules allow connection\n4. Test connection locally first\n\n### API key errors\n\n1. Double-check OPENAI_API_KEY format\n2. Verify key is active in OpenAI dashboard\n3. Check API quota hasn't been exceeded\n4. Same for Replicate token\n\n### Deployment fails\n\n1. Check build logs for errors\n2. Ensure package.json is correct\n3. Verify Node version compatibility\n4. Clear build cache and retry\n\n---\n\n## Environment Variables Reference\n\n| Variable | Value | Required | Description |\n|----------|-------|----------|-------------|\n| OPENAI_API_KEY | sk-... | Yes* | OpenAI API key for text generation |\n| OPENAI_MODEL | gpt-4o-mini | No | OpenAI model to use |\n| REPLICATE_API_TOKEN | r8_... | Yes* | Replicate token for video generation |\n| DATABASE_URL | postgresql://... | Yes | PostgreSQL connection string |\n| JWT_SECRET | random-32-chars | Yes | JWT signing secret (generate with crypto) |\n| NODE_ENV | production | Yes | Environment mode |\n| PORT | 3000 | No | Port to run on (default 3000) |\n\n*Can be omitted for offline mock mode\n\n---\n\n## Security Checklist\n\n- [ ] JWT_SECRET is long and random (32+ characters)\n- [ ] API keys are never committed to git\n- [ ] DATABASE_URL uses strong password\n- [ ] HTTPS is enabled (all platforms provide this)\n- [ ] Database backups are configured\n- [ ] Rate limiting is enabled\n- [ ] CORS is configured properly\n- [ ] Environment variables are NOT logged\n- [ ] Regular security updates applied\n\n---\n\n## Support & Resources\n\n- **Render Docs**: https://render.com/docs\n- **Railway Docs**: https://railway.app/docs\n- **Heroku Docs**: https://devcenter.heroku.com\n- **Docker Docs**: https://docs.docker.com\n- **PostgreSQL Docs**: https://www.postgresql.org/docs\n- **OpenAI Docs**: https://platform.openai.com/docs\n- **Replicate Docs**: https://replicate.com/docs\n\n---\n\n## Production URL\n\nOnce deployed, your app will be live at:\n\n```\nhttps://ai-video-game-maker.your-platform.com\n```\n\nShare this URL with users to access the studio.\n\n---\n\n**Last Updated**: October 2026\n**Version**: 3.0.0 (Production Ready)\n"
